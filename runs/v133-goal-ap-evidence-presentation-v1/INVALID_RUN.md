# Goal AP v1有效性修订

v1的128次GPU调用已完成，但不构成证据呈现A/B实验。冻结Qwen输入解码后，搜索结果实际上位于`user`角色消息的`<tool_response>…</tool_response>`包裹文本中；v1只转换`tool`角色，因此B的文档块序列化器没有触及搜索正文，A/B模型输入完全相同。v1报告中的动作相同或探针指标不能解释为呈现无收益。

所有v1输入、输出、GPU用量、失败锁存和恢复记录原样保留。AM/A的32条与Goal Z/A的32条为legacy呈现，可在v2逐条证明模型、前缀token及生成配置一致后作为A臂复用来源。两组旧B输出均不得进入v2比较。首条输出在生成成功后发生日志类型错误，随后仅补跑余下31条；没有重复该推理调用。

此修订源于输入重建和呈现映射检查，不改变原冻结语义门槛。v2独立目录先证明B输入实际变化、正文逐字保真且A输入精确复现，然后仅运行64条新的B探针。
