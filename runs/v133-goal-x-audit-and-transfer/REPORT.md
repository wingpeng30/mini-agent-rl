# Goal X：历史隔离修复与双侧证据训练可行性

## 决定

**本轮按原 Goal W 的四类覆盖门槛结束于数据缺口。没有训练或发布新模型。** 当前唯一产品模型仍为 Goal T seed 42、update32 adapter。512 道固定训练候选经逐题审核后，只有 5 道确实询问双方共同隶属关系；排除历史使用记录后有 4 道进入真实搜索。这 4 道的双侧证据均完整进入最终回答输入，因此该类最多只有 **4 个可配对上下文**，距训练类最低 16 题差 12。即使这 4 道全部制成合格 chosen/rejected，预设门槛仍无法通过。

这是一项数据与输入验收结果，**没有证明 SFT 或 DPO 在中等规模训练上的效果**，也没有得到新的搜索成功率提升。按固定停止规则，未制作其余类别的负答案、未运行四次训练、未评价新开发集或确认集的候选模型。确认集没有模型输出。

## 历史排除修复

Goal W 只汇总了 Goal G 以前的索引，遗漏了 Goal G/J 后续的实际筛查、训练和评价。已补回 AutoDL 上本地原先缺失的 Goal J `locator.jsonl`（4263 行）和 `screen-ledger.jsonl`（200 行），原始文件保存于 `remote-historical/`。完整分层来源、文件哈希、ID 与规范化问题交集见 `x0-history-exposure-index.json`；未读取旧封存 Goal V 题目、答案或输出。

| 历史接触类型 | W 训练候选重叠 | W 开发候选重叠 | W 确认候选重叠 |
|---|---:|---:|---:|
| 仅题面／ID 元数据定位 | 475 | 115 | 117 |
| 实际打开来源证据 | 26 | 7 | 4 |
| 训练输入 | 3 | 0 | 0 |
| 评价输入或输出 | 11 | 2 | 0 |

不同类型之间有重复，不能相加。仅元数据定位**不代表模型看过证据或答案**，所以单独标记；实际打开证据、训练、评价和历史支持标题碰撞进入硬排除。已知旧评价题 `5a73583e55429901807dafd0` 被正确检出并排除。

历史标题并集有 696 个规范化键；与 W 候选支持标题相交的键数为训练 **68**、开发 **22**、确认 **11**。完整语料标题相交分别为 **72/25/12**。初版历史索引扩充远程 Goal J 来源后，内嵌的交集列表未同步重算；原索引保留，独立更正见 `x0-title-intersections-corrected.json`。训练审核实际使用的 696 标题并集没有这一遗漏。实体排除以可追溯的支持文档标题及规范化题目为高精度下界，别名实体识别仍不完备；本轮未到数据冻结门槛。

## 512 题题义与证据审核

只审核 Goal W 正式版固定训练候选，不重开候选池。`semantic-question-review.jsonl` 按原顺序记录每题实际询问的属性、双方证据判断和具体理由；`training-audit.jsonl` 并列保存原关键词类、修正类、完整支持段落、历史重叠与排除原因。模型成绩没有参与逐题分类。审核由代理辅助完成，不是独立人工金标准；主 agent 复核了决定性隶属关系案例与已知泄漏题。

| 审核阶段 | 数量 |
|---|---:|
| 固定训练候选 | 512 |
| 确实询问双方共同属性 | 413 |
| 问题类别相对关键词分类改变 | 117 |
| 主要排除：历史重叠 | 40 |
| 主要排除：不是四类共同属性问题 | 104 |
| 主要排除：来源证据不足或有争议 | 26 |
| 进入一次真实搜索 | 342 |

主要排除原因互斥，逐题可有多个标志。真正询问共同隶属关系的只有 **5/512**；其中 1 题存在历史重叠，故只有 4 题进入搜索。其他原本被关键词归为“隶属关系”的题，很多实际问出生日期、职业、电影、人物交集或其他属性。四类覆盖的阻碍来自题义和隔离，而非原先报告的单一关键词计数。

## 真实搜索输入验收

固定 Goal T 起点对 342 道合格训练候选各 greedy 运行一次，共 342 条轨迹。使用 Goal Q 相同提示、BM25-v2、top-3、4 次模型调用／3 次搜索、2048 输入与 128 新 token。保存逐步工具结果、生成 token、最终回答前实际输入 token 和停止原因于 `train-real-search.jsonl`。标准答案只在生成后留作审核；模型调用只收到问题和真实工具返回。

| 修正类别 | 题义及来源合格 | 真实检索并完整呈现双侧段落 |
|---|---:|---:|
| 职业 | 173 | 172 |
| 实体类型 | 112 | 107 |
| 来源／国别 | 53 | 52 |
| 共同隶属关系 | 4 | 4 |
| **合计** | **342** | **335** |

342 条均产生最终回答；329 条搜索一次，13 条搜索两次。7 条未检索齐双方支持文档；没有提示截断、删文档或有损正文裁剪。335 条的两份支持文档 ID 与完整正文均可从最终回答前的实际输入 token 解码后核对。轨迹记录耗时合计约 **571 秒**，不是累计进程时间上限。

这里的 **335 是“可见双侧证据的上下文数量”，不是已验证的 chosen/rejected 对数**。在共同隶属关系类最多 4 对已低于预设 16 对的情况下，停止了负答案制作；有效训练对数在本轮记为 0，不能把 335 宣称为训练数据集。每个 split 的独立 2048 篇语料也尚未通过修复后的历史标题隔离，因此没有冻结新开发或确认材料供模型评价。

## 可复算性、产品决定与下一步

```bash

```

**建议另立小规模实验**，利用这 335 条真实证据上下文，先限定职业、实体类型和来源三类，制作少量经过核查的单侧属性负例，再以两 seed 比较 SFT 与 DPO。训练前仍需修复新开发／确认语料的历史标题交集、审查其题义和证据、冻结独立评分；新协议的结果不能补称 Goal W 达标。本轮不自动启动它，也不扩大到千条级。
