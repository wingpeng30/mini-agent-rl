# v133 Goal C 分支判定

日期：2026-09-27  
状态：条件未满足；本轮不启动训练或正式验证。

## 判定

Goal B 的错误信号目前不足以支持一个明确、可监督的小规模 SFT 目标，也不足以支持另建一组正式验证实验。按 v133 S4 的规则，本轮选“证据不足，停止该分支”，不启动训练、不扩池、不访问封存独立100题或 final-test。

## 依据

- A3 未通过预注册晋级门槛：严格 EM 净增 +2/50（门槛至少 +3），A2 正确保留率 92.86%（门槛至少 95%）。因此不提出 A3 的独立正式验证方案。
- Luna 在22个预注册审核案例中给出“答案抽取错误”标签10次；标签允许重叠，且该分类没有覆盖全部50题。仅2个这类案例有有效 DeepSeek 双审。在这2个案例里，没有候选同时得到两位审核者“答案错误或不完整、但作答时证据为 supported/partial”的共同判断。其余8个标签没有有效 DeepSeek 复核，不能当作确认的训练目标。
- 现有训练候选预检报告为278个状态、175道题、37组严格配对。预检说明这些是候选，不自动构成可训练集；报告未将这些配对映射到本轮经双审确认的答案抽取错误。当前也没有一份符合边界、可直接用于该目标的已核验样本清单。因此不能从“有候选和训练脚本”推导出应训练。
- 盲审最终覆盖为12/22双审、10/22只有 Luna；A3新增正确答案中只有1/4取得双审支持。本轮交付接受该部分覆盖，但单审标签不进入合格训练集。

## 唯一关键缺口

需要出现一类可重复、经有效双审确认的具体失败：两位审核者都能指出同一候选在作答时已有支持证据，却稳定漏抽或抽错了所需答案；并且能映射到已有真实、来源可追溯、标签合格的监督样本。若之后满足这一点，再另行提出小规模 SFT 对照，明确训练目标、样本清单、token预算、基线、评估题与停止门槛。训练和新来源筛查仍需单独明确授权。
