# Goal K：迁移收益归因与审核补全

## 结论

Goal J 的新评价集严格EM从9/16升至10/16；两侧均为有效 answer 的13题子集保持9/13，F1从0.7500升到0.7821。全体F1从0.6094升到0.7813，协议有效输出从13题增至16题。新增严格正确2题、丢失1题。

因此，当前16题新评价集上可观察到的严格EM净增主要来自原本继续搜索的一题转为正确回答；在两侧原本都能有效回答的子集中，严格正确没有净增，J-039的答案改进与J-072的粒度退步相抵。协议有效率和整体F1明显提高，但本轮没有证据证明共同属性选择在新评价集上出现净严格EM收益。

Goal G回归集的严格EM从3/16升至9/16；限于训练前后都能有效回答的14题时，严格EM从3/14升至8/14。该集曾参与先前研究决策，所以这是探索性回归信号，不能代替新隔离评价结果。

合法的最终search动作与无法解析的原始输出在台账中分别编码。EM、F1和主结果没有因事后归因或语义判断而改写。固定有效答案子集是事后诊断，不是预注册主指标，也不能单独证明因果。

## 训练数据流核查与文档更正

静态核查显示，Goal J运行器在训练前通过 `frozen_inputs()` 把新评价样本读入进程内存；因此运行态里“adapter冻结后才读取评价集”的原表述不准确。随后训练调用只接收冻结训练文件，`validation_path=null`、Trainer的`eval_dataset=None`、`validation_samples=0`、`evaluation_enabled=false`，代码没有按评价指标挑checkpoint。证据支持“评价数据没有进入训练或checkpoint选择”，但结论基于代码与配置的数据流核查，不声称其从未出现在训练进程内存。Goal J原报告已更正。
