# 4090D 资源限制调整（2026-09-17）

已同步到 AutoDL 44249 实例，完整远端回归 61 passed。

## 修复

- collect-rl 实际传递 retriever_version，修复声明 BM25 而使用默认检索器的问题。
- 独立保存采样报告路径，避免结果字典覆盖路径导致写报告失败。
- 从 usage 顶层读取有损裁剪、无损表达与文档删除计数。
- 最终 gate 失败时状态为 GATE_FAILED，无参数更新也留下失败诊断。
- 检查 prompt mask 与 action mask；保留有限数值和数据隔离要求。

## 解除限制

- harness 不再限制最多 1800 秒；任意非负秒数有效，0 为不限时。
- train-grpo 默认输入提高到 2048，仍允许显式指定更长输入。
- 新增 --no-gradient-checkpointing、--max-new-tokens 和 --generation-timeout（默认600秒）。
- BF16 无需新增依赖；省略 --load-in-4bit 即使用 BF16。
- 新配置 configs/4090d-bf16.toml 使用 BF16、关闭梯度检查点、20×4、21GiB 显存预算和6小时超时。
- 任务数、group size、max steps 原本可配置，没有额外上限。并发模型锁仍保留：移除锁不等于真正批处理，会破坏随机种子与模型状态隔离。

## 新机器实测

脚本 scripts/benchmark_24gb.py：合成2048输入、128输出、每次更新2条transition、2次AdamW更新，192个optimizer参数状态。不是模型效果评测，不保存checkpoint。

| 配置 | 训练段耗时 | 峰值reserved |
| --- | ---: | ---: |
| 4-bit + 梯度检查点 | 9.466秒 | 3.545GiB |
| BF16 + 关闭梯度检查点 | 6.323秒 | 14.352GiB |

两配置loss/梯度有限并完成全部更新。第二种组合训练段约快1.50倍，耗时减少33.2%。这是一次合成负载测量，不能等同于端到端采样吞吐或效果提升；同时改变精度与检查点，不能归因给单一因素。

旧20×4采样已结束，日志证实报告路径TypeError；其检索器与预期不一致，保留原产物，不能用作BM25训练资格证据。BF16训练必须重新采集匹配配置的轨迹与质量基线。
