# v121 固定状态停止与查询约束实验

状态：开发实验完成，候选门槛未通过；不启动完整端到端补跑、SFT、GRPO 或独立100题。

## 目标与边界

本实验比较停止判断与实体约束查询能否改善检索后的决策。v118 adapter、50道固定开发题、v117冻结的1,986篇语料、BM25-v2 top3、2048 token输入预算、关闭 thinking、确定性解码和 seed 42 均保持不变。每题最多两次搜索，重复查询不消耗搜索次数，最多修复一次。四组都从同一首轮检索状态继续，因此这是固定状态消融诊断，不是完整替代轨迹的因果结论。

没有访问独立100题或 `final-test`。DeepSeek 仅用于离线盲审，不参与模型运行时决策。

## 实现与观测

实验驱动层新增了决策前实际输入 token、attention mask、提示哈希、截断后可见证据片段与原始输出记录；生成采样记录与后续 log-prob 重放分开选择，避免误将重放上下文当作模型真实输入。审核检查器收到单独构建的中性材料，其中只包含问题及当时截断后可见的证据片段，不带之后检索到的证据。

smoke-v3/v4与完整固定状态运行显示，小模型没有稳定按提示输出查询复核或证据充分性 JSON 协议：即使把检查轮次从既有动作历史中隔离，控制器仍会输出无效字段、占位事实或直接输出搜索动作。这是明确的协议/控制调用能力失败。它说明当前“让同一小模型再做一次自我检查”的实现不可用；不能据此证明模型本体无法判断证据，也不能证明停止规则本身无效。由于没有合规的检查输出，Q或S的语义质量仍无法干净估计。

A的两次未完成案例来自模型给出的重复查询修复不合法，运行器正确拦截后停止；这验证了阻断分支，但没有增加检索次数。第一次检索后的固定状态也继承v120提出的首轮查询，所以本实验不评价首跳检索覆盖质量。

## 盲审

50题的 A/B 匿名材料由已获授权的 DeepSeek API 离线盲审。最终审核每题提供问题、逐决策截断后可见证据、匿名动作/输出、检索结果，以及搜索后下一决策实际可见证据；不发送 gold、评分、任务ID或模型/策略名称。每题独立随机交换两个匿名轨迹编号，编号与策略的对应关系在题间变化。程序校验审阅引用是否为指定决策或检索片段的逐字子串。

最终盲审中98/100条轨迹通过结构和引用校验；两条 B 轨迹的引用不合法，保留为未解决并排除于语义计数。48/50题的两条轨迹都有效。校验后的审核结果为：

- A产生48个答案，其中28个被判为受证据支持、20个不受支持；另2题没有最终答案。
- B产生4个答案，均被判为不受支持；其余46题在控制器协议失败后没有最终答案。两条 B 轨迹因审核引用问题未计入上述判断。
- A的44次已执行第二跳搜索中，31次查询被判为瞄准明确缺口，13次没有；32次检索在下一步实际可见证据中补入所缺关系，12次没有。首跳为两组共享的固定检索，不能归因给任一组。
- B没有执行第二跳检索：46题的查询复核调用未通过协议，因而 Q 的语义效果仍不可识别。模型提出的查询不能当成已执行搜索。

检查器的审核结果仅描述可见证据和动作支持，不以 gold 判分。执行前的另一轮盲审因响应包装、引用和匿名编号验证问题而作废，保留在独立原始记录中，不并入最终统计。

## 决策

当前证据支持的结论是：v120策略在已有关系缺口时的第二跳搜索常能补到缺失关系；查询目标选择仍有明显错误。Q/S控制器先被动作协议和同模型自检调用失败阻断，因此本轮不能证明约束策略会提升端到端正确率。问题主要出在“当前模型＋控制器提示＋外层动作协议”的组合；由于本轮没有做示例对照，不能将问题归为示例不足。不能仅凭这批结果判断模型本体是否具备稳定自检能力。

下一步先构造双审、引用绑定的“缺关系→搜索／关系齐全→回答”训练状态，尤其覆盖未执行查询、无效搜索与充分证据后的停止；数据通过隔离和类别门槛后，再决定是否为检查决策做小规模 SFT。不要继续堆提示词、不要把这轮失败的控制器输出当训练标签。新实验必须先通过短协议与证据时序 smoke，再预注册50题对照；满足门槛之前不进入独立100题验证。
