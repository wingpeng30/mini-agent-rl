# Goal Y：三类真实证据缺陷训练对与干净新题检验

## 问题与边界

从 Goal X 已保存的 335 条真实双侧证据可见的回答前上下文中，检验经人工核实的同属性证据缺陷偏好对，能否提高自然段落新题的搜索问答成功率。只研究职业、实体类型、来源；沿用 Goal T seed 42 update 32 起点、Goal Q 搜索入口和既有参数。不添加题目，不访问旧封存集，不改变历史评分。

## Y0：冻结数据与判据

训练仅使用 Goal W 一次性冻结的训练候选和 Goal X 真实搜索输入。每个训练对须有两侧全文实际可见，chosen 完整回答共同属性且两侧证据支持，rejected 回答同一属性但至少一侧明确不支持或与之冲突。等价表达、仅措辞差别、不同属性和证据不确定的答案不得作负例。每对保存两侧原文摘录、缺陷类型和审核理由；主执行者逐条复核。训练题不超过 48 道，职业、实体类型、来源各 16 道，按 Goal X 固定顺序取审核通过者。达不到任一配额即结束并公布缺口，不事后改配额。

新开发、新确认分别从 Goal W 原 128 道候选中按原固定顺序选 48 道，各类 16 道。排除旧训练或评价已使用的问题、主体、支持标题，以及历史标题覆盖的语料文档。两套题、标题及语料彼此隔离；数据质量只依据题义和来源证据，不依据模型成绩。确认题和答案在开发选模前隔离。任一 split 不足即结束。保留被排除项目及原因。

评分在任何新模型输出前冻结：主要指标是答案正确、信息充分、由实际可见双侧证据支持；无法判定计失败。另报严格 EM、F1、事实错误、单侧证据错误、无效动作、搜索次数与延迟。相同问题、证据、答案组合只审一次，隐藏模型身份并保留理由。代理辅助审核不称为独立人工金标准。

## Y1：冻结起点和成对训练

先复现旧 32 题起点 20/32 EM、回归 7/16、无效动作 0，再评价新开发起点。若新开发成功超过 45/48，则 +3 门槛不可达到，停止训练并报告评价空间不足。

从同一 Goal T adapter 独立训练普通 chosen 答案 SFT 与同上下文 chosen/rejected DPO；seed 42、43 各一，共四次。每次一遍、48 次更新。A/B 共用冻结题序与真实回答前 token；只监督最终 answer 动作及终止符。沿用 Goal U 的学习率 5e-6、AdamW、梯度裁剪 1、DPO β=0.1，DPO reference 冻结为原 Goal T。训练全部结束后统一评价预定末尾 checkpoint，检查 LoRA/base、独立重载、输入及更新数。不设 GPU 时间上限；记录耗时和资源，基础设施、权重或数值失败停止，不自动重试或调参。

## Y2：开发、回归、确认

四个候选均跑新开发 48 道和旧 32 道完整搜索，保存原始工具结果和输入 token。起点与候选在相同起点回答前上下文做固定输入诊断，以区分检索和回答变化。路线仅在两个 seed 均满足以下条件时进入确认：新开发成功数比起点至少 +3/48；事实错误、单侧证据错误和无效动作均不增加；旧主要与回归两组的语义成功数各不下降；工程及重载检查通过。

若两路线合格，依次按两个 seed 中较低成功数、平均成功数、较少事实错误选一条，完全并列选 SFT。然后才打开确认集，仅跑起点及胜出路线两个 seed，各 48 道。两个 seed 均须比确认起点至少 +3/48，且事实错误、单侧证据错误、无效动作均不增加，才发布该路线 seed 42 checkpoint。否则保留 Goal T 产品模型，不试另一条路线或改训练材料。

## 交付

独立目录 `runs/v133-goal-y-three-class-transfer/` 保存训练对及证据审核、清洁题及排除台账、冻结哈希、配置、训练曲线、所有适用模型的逐题和汇总结果、盲审理由、确认门槛决定和唯一产品推荐。新增 `prepare/run/summarize` 接口，运行拒绝覆盖。README 记录可复现命令及结论。若数据门槛失败，明确报告实际可训练数量，不把准备结果表述为模型收益。

## Y0 审核结果与单独的小规模验证

原 48 对目标不可行：真实证据审核仅找到职业 12、实体类型 8、来源 5，共 25 对。因此原均衡 48 对方案按预设门槛结束，不能称为完成 Goal W 的 128 对扩展。

在任何新模型输出产生前，另行冻结一次 **25 对可行性验证**，明确与原计划分开报告。只使用已审核的这 25 对，不增写负例；两臂、两个 seed、同一起点和优化配置不变，每次固定一遍、25 次更新。新开发和确认仍各 48 题、三类各 16，不因训练类别不均衡改变评价组成。新开发 +3/48 与旧题不回归门槛、确认 +3/48 门槛保持不变。若 25 对中有一条在主审中未通过，停止这次小规模验证，不用后补对替换。该小规模验证只回答“这 25 对是否足以产生可重复的新题收益”，不用于宣称中等规模训练方案成功。
