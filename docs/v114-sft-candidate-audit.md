# v114 证据约束 SFT 候选数据审计

日期：2026-09-24

## 结果

完整 HotpotQA `distractor` 训练 split 含 90,447 题。按问题 ID 与 NFKC/casefold 规范化问题文本，排除项目本地可读训练、诊断、导出及评测记录中的历史重合后，剩余 89,634 道唯一题；另有 13 条规范化重复记录被去重。历史排除清单和原始来源哈希记录在 `data/evidence-sft-v114-clean/source-audit.json` 与 `data/hotpot-full-train-v114/download-provenance.json`。

在生成任何候选状态前，按固定 SHA256 规则冻结了新的内部 50 题和 220 道训练候选题。训练与内部题目 ID 不相交，各自使用独立文档语料。构造状态只使用官方训练题上下文中的原始段落和支持句；搜索查询只由问题文本和当时可见文档生成。没有导入教师答案。

训练候选达到结构门槛：320 个状态、197 道题，其中 160 个充分证据回答、128 个已有证据但仍有明确缺口的搜索、32 个初始搜索。四类风险状态数为关系 320、时间 97、范围 273、测量 40。

内部候选未过门槛：目前 99 个状态覆盖 49/50 道冻结题，其中 49 个充分证据回答、40 个已有证据搜索、10 个初始搜索。原要求是至少 100 个状态覆盖全部 50 题。未用另一题替换未覆盖的问题，因为这会在看到候选可用性后改变冻结集。

## 结构核验与盲审

逐条结构审计检查了 419 个候选：回答目标的每条 Hotpot 支持句都能在模型输入中找到；搜索目标查询能从问题或可见证据中逐词追溯；搜索结果包含新的缺失支持句；输入引用均指向实际出现的文档；训练和内部题目隔离无重合。以上检查均通过。

结构核验不等于语义双审。所有候选的人工/独立语义审核状态仍为空；没有样本被计为已批准。完整盲审材料分别位于 `data/evidence-sft-v114-clean/reviewer-a.jsonl` 和 `reviewer-b.jsonl`，gold 与源题映射单独保存在 `private-key.jsonl`。`structural-audit.json` 和 `manifest.json` 提供逐文件哈希。

## 隔离事件

本次最初的历史扫描错误地读取了名为 `final-test.jsonl` 的文件；该批冻结和候选已整体隔离，不可训练或评测。过滤器已修正，清洁重建使用新的输出目录，并按所有路径部分匹配 `final-test`、`holdout`、`independent100` 屏蔽。事件细节见 `docs/v114-isolation-incident.md`。独立 100 题内容没有读取。

## 阶段决定

训练来源和训练候选规模达标，但内部候选题覆盖少一道，且独立语义双审尚未完成。因此当前 SFT 数据门槛失败，训练保持禁止；不进入小规模 SFT、独立 100 题评测或 GRPO。需要先由两名独立审核者完成盲审，并解决内部 50 题的一个覆盖缺口，同时不改动已冻结题目集。
