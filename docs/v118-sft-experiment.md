# v118 受控 SFT 试验

## 冻结数据与目标

v118 使用 v117 冻结训练集（345个状态、186道题、75组完整搜索/回答配对）和内部验收集（50道题、100个状态）。训练导出 SHA256 为 `26ced5bafb5210fefe9b007915598c8d58d2ebec156e938a48d86e1f1577ad8b`，内部导出为 `1a33ec08d5b23a365f0b679034806cfb89bdb48c59711db72b98dc253a4ab4f0`，内部固定语料为 `989d7ea08187dfdbf2a07d69cbf6a8d7dd1127ac6d971c9f62b365475f46cea9`（1,986篇文档）。v117本地门槛全部通过，归档完整性逐文件核验。

训练从冻结 v101 adapter 开始，单次5步 smoke 通过后，从同一冻结 v101 重新起步做50步正式训练。固定 BF16、学习率 `5e-6`、batch 1、累积8、seed42；正式使用最后 checkpoint。内部集仅用于评估。v101为主对照，v112作参考。v111的78%是训练侧 API 混合流程成绩，不是本地模型成绩。

## 远端前置与运行

远端训练必须先通过 `scripts/preflight_v118.py`：GPU支持BF16、依赖与磁盘可用、v101/v112 adapter权重哈希正确，冻结数据哈希通过，且本地与远端345+100条逐条 token ID、截断和目标掩码完全一致。模型输入、目标、总长上限分别是2048、128和2176。任何检查失败都阻止训练。

先运行 `scripts/train_v118.py --phase smoke`。报告显示恰好5次更新、有限loss/梯度、权重有变化、checkpoint可重载且v101未变化后，才能以该 smoke 报告运行正式阶段。正式训练必须恰好50次优化器更新，并加载 `checkpoint-50`；不继承smoke权重，不根据中间指标选点或补训。

`scripts/evaluate_v118.py` 在相同的v117语料、BM25 top3、模板、上下文预算和解码配置下运行 v101、v112及正式 adapter 的100个固定状态和50道完整题。任务协议率按每个实际动作的解析及动作结构是否合法计算；完成率、重复动作、达到步数上限和工具错误另行报告。

## 验收与盲审

内部门槛须同时满足：协议率≥98%；充分证据回答正确≥45/50；证据不足时搜索≥45/50；v101原正确答案保留率≥95%；端到端净增正确≥3；F1不下降；双审没有未解决争议或确认语义退化。

对全部100个状态及模型答案不同的题目生成匿名盲审包。包中隐藏模型名、目标动作、gold与分数，状态证据截至动作前，搜索后top3单独呈现；端到端答案仅使用回答前实际可见历史。一个 `gpt-6-luna` low 子 agent 与 DeepSeek API独立审核。引用分别校验到候选自己的动作前证据或搜索后结果。分歧、无效引用或不确定结论保留为未解决并阻断下一阶段。

仅当内部数字和语义门槛全部通过，才能冻结代码、adapter、数据和配置，并授权打开独立100题。在原冻结986文档环境完整配对运行v101和新adapter；要求净增正确≥3、F1不下降、保留率≥95%、协议率≥98%、没有未解决语义问题，并且seed42、10,000次配对bootstrap的EM差值95%置信区间下界大于0。未通过则停止，不按中途结果调参。通过后只提交GRPO方案，本轮不启动GRPO。始终禁止访问 `final-test`。

## v118 实际执行结果

2026-09-25在新AutoDL实例完成前置核验、5步 smoke、从冻结v101重新起步的50步训练，以及三模型的相同输入固定状态与50题端到端评测。GPU为RTX 4090D，BF16可用；训练依赖、源adapter哈希、冻结数据和345+100状态的逐token审计均通过。Smoke与正式训练均有限loss/梯度、checkpoint可重载，v101源权重未变化。正式adapter SHA256为 `ea894d235b6779bc8d15d1327a953773f946c347dfa7fa55ee3d2c2d5bd4a0a5`。

正式训练报告中的 `trainer_validation_sha256` 与训练集SHA相同，所报 `eval_loss` 是训练集上的辅助诊断，不是独立验证成绩。内部100状态在整个训练过程中没有参与训练或梯度更新。

同一1,986文档语料和冻结评测配置下，内部50题端到端结果为：v101 EM 9/50（18%）、token F1 0.240；v112 EM 24/50（48%）、F1 0.553；v118 EM 14/50（28%）、F1 0.340。v118相对v101有6题增、1题退，净增5，但保留v101原正确答案为8/9（88.9%），低于95%门槛；相对v112仍低10题。三者协议动作率均为100%，v118回答完成率96%、重复动作2、工具错误0。

固定100状态诊断中，v101为充分证据答案正确39/50（78%）、证据不足时搜索23/50（46%）；v112为33/50（66%）、50/50（100%）；v118为37/50（74%）、42/50（84%）。v118将搜索率较v101提高38个百分点，但回答正确率低4个百分点；它没有达到搜索或回答各自45/50的门槛。v118的搜索输出在42/50个不足证据状态上带来至少一篇不同于当前证据的新top3文档；这是文档新颖率，不代表它包含相关的新事实。协议率100%。这只能描述固定输入诊断，不足以单独作动作策略的因果归因。

数字门槛汇总：协议≥98%、端到端净增≥3、F1不下降通过；充分证据回答≥45/50、证据不足搜索≥45/50、原正确答案保留率≥95%未通过。因此内部验收失败，本轮停止，不访问独立100题、不访问 `final-test`、不启动GRPO，也不追加训练。v111的78%仍只代表训练侧API混合流程，不是本地模型结果。

对100状态及26道答案变化题已完成匿名双审，覆盖两名审核者各自的全部案例与A/B/C候选。Luna审核记录的引文均通过盲包原始文本校验；DeepSeek审核中仍有不匹配实际可见文本的引文，最多两次更正后仍未解决的引用被保留为无效。合并报告累计记为492项未解决记录（包括无效引用、双审分歧与不确定结论），并标出1项候选语义退化；该项不应脱离其引用有效性问题解释为已确认的模型退化，因此语义门槛失败。这里的“完整覆盖”只表示每个案例均有审核记录，不代表每条引用有效或意见一致。独立审核API配置来自项目外 `.env`，不进入代码仓库或备份归档。

训练、SMOKE、逐题结果、匿名盲审包和私有模型映射已归档到本地 `backups/v118/v118-private-results-lean.tar.gz`，SHA256 `38a44bced158676b88ef5141b2f6ead0a21dfdad4949645b4835c20bfc3b1a3f`，归档可读取且包含正式adapter及评测产物；完整的116.7MB归档因浏览器下载取消而未采用。最终审核与门槛报告另存于 `backups/v118/v118-final-review-addendum.zip`，SHA256 `a221de9c78a7939174a73fcbabad29d69b5251fd9d3879cc3d64e83f6363c758`，ZIP完整性及所含文件哈希均通过。当前修正引文校验及自动化测试5项通过。远端实例在最终本地备份及代码上传后按用户指示发送关机命令，不轮询关机状态。

最终合并审核保存在本地 `backups/v118/reviews/semantic-gate.json`；它以冻结盲审包哈希为绑定，100个状态与26个答案变化案例均有双审覆盖，但因引用、意见和确定性问题，`semantic_gate_passed=false`。数值门槛汇总见本地评测目录 `backups/v118/extracted/runs/v118/eval/internal-final-gate.json`。数值与语义门槛均未全部满足，故独立100题未开启，`final-test`未访问。本轮只得出“该次50步SFT未通过预注册验收”的结论，不据此断言所有SFT均无效。
