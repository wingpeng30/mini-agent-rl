# v117 本地 SFT 前数据准备

v116 未放行的直接原因是内部集双审后只有32道完整配对题、范围风险仅2状态。先选50题再构建共享语料，使替换题目改变其余题的检索输入，导致审核无法复用；只按官方支持句构造状态还会放过提前可答、关系或时间范围错误的例子。v117 因此先固定更大的候选语料，在最终截断输入上检查检索收益并双审，再从合格配对中选50题。旧内部题和 v115 诊断保留作开发分析。

## 固定来源与语料

v116 训练侧已经通过：345 状态、186 题、75 道非空搜索与回答完整配对；回答156、非空搜索177、空搜索12。原始双审、审查包和 token 重放记录保留在 `data/evidence-sft-v116`。v115 原始诊断及证据支持争议原样保留，不能将未解决的判断解释成遗忘。

v117 从官方 HotpotQA distractor 训练分片按 `SHA256("v117-internal:"+问题ID)` 排序，最多预筛2,000题。历史清单复用 v116 的零失败基线并扫描 v116 的候选、审核和诊断输出；不读取封存评测内容。旧 pytest 和 v113 暂存目录被单列为临时产物，不作为新候选来源；任何其他扫描失败阻断放行。题目ID与规范化题面都用于历史暴露隔离。

预筛后固定200题，官方上下文按文档内容去重，共1,986篇。`candidate-freeze.json` 绑定题目顺序、检索 top3 和 `candidate-corpus-private.json` 的 SHA256。所有候选与后续三模型内部验收都使用这份语料，最终入选50题不触发重建。与旧内部集的绝对成绩不直接比较。

## 状态构造与审核

固定语料中，168题能构造程序化搜索与回答配对。实际模板和2048 token 截断之后，167题的334状态通过程序检查；另外33题留有逐题淘汰原因。程序检查包括非空搜索前证据、top3 新增文档及缺失标注事实、查询词来源、回答证据在截断后仍可见。程序通过不代表语义合格；官方支持句标注只用于初筛。

审核包只含题目、最终实际输入、匿名目标动作及搜索后 top3；不含 gold、模型身份或私人来源映射。搜索后文档仅证明该次检索收益。独立 Luna 子 agent 与 `.env` 配置的 DeepSeek 分批审核同一批包；每批至多20状态，审查结果立即落盘。批准要求完整语义证据和合法逐字引用；搜索必须同时满足确有缺失事实、查询有依据、top3新增相关事实。争议、单审、无效引文及孤立状态隔离。风险标签取双方批准时的交集，不把普通问词自动计入范围。

最终按预设哈希顺序，从双审合格的完整配对中确定性取50题，同时满足关系、时间、范围、测量每类至少5状态。已固定语料中的其余题仅作本轮备用，不转入训练。审核达到门槛即停止；若167题耗尽仍不够，则报告缺口，不放行。

## 放行与下一步

本地门槛包括：训练300–400状态、至少150题、至少75完整配对；回答45%–55%、非空证据搜索至少40%、空证据搜索至多10%；训练四类风险各至少20状态。内部恰好50题、100状态，各风险至少5状态。两集合的问题ID及规范化题面隔离，内部题与历史暴露隔离；输入≤2048、目标≤128、总长≤2176，并校验目标掩码、逐token及截断后证据。

训练导出只含 SFT 输入与目标动作；审核、gold和源ID映射单独保存。下次训练固定从 v101 分别复制 adapter 做5步 smoke 与重新起步的50步正式训练，使用最后 checkpoint。AutoDL 仍关机，远端 GPU、磁盘、环境、v101/v112 权重哈希和本地／远端逐token一致性须在下次开机后、训练前复核。本轮不启动 SFT，也不访问独立100题或 `final-test`。v111 的78%仍是训练侧 API 混合流程成绩。

## 完成结果与冻结边界

Luna 独立审核到第12批即停止：240状态；DeepSeek 已审核334状态。首批 Luna 风险字段格式错误和统一范围分类的26条更正均保留原记录，并以追加侧表记录。两者一致批准形成51道完整配对题；按固定哈希规则选50题、100状态。入选状态的双审风险交集为关系49、时间28、范围8、测量11，全部超过最低5条。余下94状态没有 Luna 审核，保持单审隔离，不能用于最终集；第13–17批没有 Luna 输出。`review/audit-stop.json` 绑定第12批停止点与最终选题顺序。

`reports/v117-local-preflight.json` 的本地检查全部通过。导出为345状态训练、100状态内部，任务50题和完整1,986文档语料另存于 `frozen`，对应哈希见两个冻结 manifest。训练文件只含 `messages`、`target_assistant_index`、`thinking_enabled`；任务答案、来源映射和审核记录存于私有文件。新内部环境采用现有评测器所需的任务、状态、语料和清单格式；三模型评测必须使用同一语料哈希。

50个入选搜索状态已对冻结语料重新执行 BM25 top3，文档ID、标题、正文与盲审包逐项相同；运行时返回的数值 `score` 字段不属于证据正文，审核包未包含该字段。复算报告见 `retrieval-replay.json`。334个候选的本地输入 token、目标掩码和截断后可见文档此前也逐条重放一致。

`tests/test_v116_review.py` 与 `tests/test_v117_data.py` 合计12项检查通过，覆盖引用边界、部分或重复审核、哈希阻断、搜索新增证据、截断后答案证据和风险选择门槛。`finalize_v117.py` 在固定停止点再次通过，输出的训练345条、内部100条、任务50条及语料1,986篇的文件哈希均与冻结清单一致。

两个旧 v113 暂存目录经只读检查确认各有0个子项，记录在 `history-scratch-verification.json`。v116 原始报告及备份未改动；v117 放行器逐项核对 v116 训练导出、门槛报告、token 重放报告与原备份清单。

**本地数据准备通过，训练仍不允许启动。** AutoDL 关机期间无法完成远端 GPU、磁盘、环境、v101/v112 权重及本地／远端逐token一致性核验；这些是下次开机后的启动前门槛。本轮没有训练或访问独立100题、`final-test`。最终依据 `reports/v117-local-preflight.json`、`data/evidence-sft-v117/frozen/manifest.json` 和备份清单。
